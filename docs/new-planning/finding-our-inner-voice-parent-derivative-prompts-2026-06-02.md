# Finding Our Inner Voice - Parent-Derivative Image Prompts

Date: 2026-06-02

Use these prompts when remaking the 14 new images so they stay inside the original visual universe.

Recommended workflow:

1. Use GPT first for the creative generation because it is usually better at obeying named-file edit and preservation instructions.
2. Generate at the highest square resolution available, ideally 4K.
3. Once an image is compositionally accepted, use Nano Banana / Gemini only for upscaling with this narrow instruction:

```text
Upscale this image to the highest available resolution. Preserve the image exactly: same composition, same objects, same colors, same lighting, same texture, same linework, same aspect ratio. Do not redesign, reinterpret, add, remove, restyle, simplify, or enhance creatively. Only increase resolution and preserve print-quality detail.
```

Do not upload failed remakes unless a prompt explicitly asks for one. The safest strategy is to derive each new page from an original production image.
