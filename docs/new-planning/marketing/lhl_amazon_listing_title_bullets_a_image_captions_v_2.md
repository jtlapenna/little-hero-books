## Notes for Designer

- Avoid heavy text on images (Amazon guidelines).
- Use large, legible captions when allowed.
- Keep a consistent warm color palette: soft cream, watercolor pastels, no high-saturation primary colors.
- Ensure primary image is clean, high-res (2000×2000 minimum), pure white background.
- A+ banner module is ~970×600. Other modules vary; check current Amazon spec.
- Where possible, reuse the IG-launch creative library at `docs/marketing/instagram-launch/posts/` — they're cohesive and on-brand. Notes on which IG asset maps to which module live in the implementation guide.
