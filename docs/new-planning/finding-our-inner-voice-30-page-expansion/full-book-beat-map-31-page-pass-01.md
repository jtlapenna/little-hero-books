## Current Locked Directions

- Pages 4-15 are directionally locked from the rough page-copy pass.
- Pages 16-23 are directionally accepted, with the cave/self-critic wording still open for refinement.
- Pages 24-31 are directionally locked as of 2026-06-06 and should be refined during visual passes.
- The animal guide should not feel like a separate outside authority; it is the child's quiet inside voice in visible dream form.
- The ending should not imply that listening always means doing the scary thing immediately. The confident choice is "You go first. I'm almost ready."

## Next Recommended Phase: Imagery Concepts

Move into page-by-page imagery concepts with a story-first lens, then reconcile against reusable assets. The strongest first pass should define:

1. One main visual action per page.
2. Whether the child must appear.
3. Whether an existing pose can support the page.
4. Whether an existing background can support the page.
5. Whether the page can be background-only, animal-only, or end-matter art.

Start with the highest-risk visual sequences:

1. Park/slide setup and return payoff.
2. Cave wall / word transformation sequence.
3. Animal clue / reveal sequence.
4. Flying return into slide.
