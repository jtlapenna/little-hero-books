# Imagery Concepts Pass 01

## Purpose

This document is the story-first imagery pass for the expanded version of *Finding Our Inner Voice*.

The goal is to decide what each page needs to communicate visually before deciding whether to reuse existing assets, generate new backgrounds, or generate new personalized child poses.

## Working Method

For each page, lock these in order:

1. The one main visual action or image idea.
2. Whether the personalized child must be visible.
3. Whether the animal guide is visible, clue-only, or absent.
4. Whether the page can reuse an existing background or needs purpose-built art.
5. Whether the page can reuse an existing child pose, needs a new pose, or needs no pose.
