Finding Our Inner Voice - Storyboard Pass 02

Spread-level storyboard for the expanded book. This pass places text directly on the page art and marks the intended negative space so image prompts can reserve room for type.

Text Style Direction

  • Set story text directly on the illustration, not in a text box.
  • Reserve quiet negative space inside each composition for live text.
  • Let text position vary by page so it feels naturally placed.
  • Use readable dark ink over light, low-detail areas with a subtle soft shadow only if needed.
  • Avoid covering the child, animal clues, key action, or emotional focal point.

Prompt Implications

  • Every background prompt should specify an open, low-detail text area.
  • Text-safe areas should be part of the composition, not an empty pasted-on rectangle.
  • Pages with more copy need larger calm areas and simpler nearby texture.
  • Final image prompts should say not to include readable text inside the generated art.
