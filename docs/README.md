# Individual Repository Documentation

This directory contains detailed audit documentation for each GitHub repository.

## Structure

Each repository should have its own markdown file named after the repository (e.g., `little-hero-books.md`).

## Usage

1. Copy `../repo-documentation-template.md` to create a new repository audit document
2. Name the file after the repository (e.g., `little-hero-books.md`)
3. Fill in all applicable sections using the template
4. Update the master inventory (`../repo-inventory.md`) with a link to this documentation

## File Naming Convention

- Use lowercase repository names
- Replace hyphens with hyphens (keep original format)
- Use `.md` extension
- Examples:
  - `little-hero-books.md`
  - `tpb-store-modal.md`
  - `multi-agent-content-system.md`

## Documentation Process

1. **Audit Repository** - Use `../audit-workflow.md` as guide
2. **Document Findings** - Use template to document everything
3. **Assess Risks** - Calculate risk score
4. **Make Decision** - Determine public vs private
5. **Create Migration Plan** - If making private, use `../migration-plan-template.md`
6. **Update Inventory** - Add entry to `../repo-inventory.md`
