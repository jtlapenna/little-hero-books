# Frozen character handoff evidence

W0 could persist a character hash on the order while omitting it from the frozen manifest. W1 then held that manifest because its character prefix did not match the order. The fix carries the existing hash through normalization and resolves the existing visual fallback once for both outputs.

W1 also used global `fetch` in a Code node, where that function was unavailable. Its transport now uses the supported `this.helpers.httpRequest` helper. The W1 handoff suite removes global `fetch`, supplies the helper response shape and checks GET, JSON, full response, a 15-second timeout, no redirects and timeout recovery. The separate actual n8n engine proof remains in the release record.

This successor binds every source path from the shipped controlled pipeline evidence, plus the focused character handoff test and the W0 publication regression tests. The earlier package remains unchanged. CI verifies its historical receipts without `--source`, then verifies this package against current source hashes. Neither its earlier 30-suite result nor older auth, typecheck or live claims are renewed here.

`checks.json` records the ten actual local suite commands, exit codes and output hashes against one source snapshot. Those suites cover the new hash handoff, read-only W0 construction, Worker publication, frozen reuse, legacy intake, deployed selection, W1 handoff and W2A base, pose and frozen generation input. The runner inherits only `HOME` and `PATH`. Tests use synthetic services, VM fixtures and isolated Workers. The separate HTTP and PostgreSQL proof belongs to the release record and is not claimed by these local results.

The verifier checks current hashes, complete prior source coverage, exact suite commands and successful exits. It then verifies the prior package, which retains its own historical evidence chain. Mutation tests use disposable copies to confirm rejection of runtime drift, lost prior coverage, a failed suite and changed output.

No live credential, provider, order, deployment or print action is part of this package. It grants no execution or installation authority. Previously frozen manifests with mismatched character identity remain held. This fix does not rewrite them.

From the repository root:

```sh

```
