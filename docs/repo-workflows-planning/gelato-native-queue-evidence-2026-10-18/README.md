# Gelato native queue local evidence

This package records local tests and archived-definition preparation. It contains no importable private workflow or credentials. It does not establish a hosted n8n run, real provider response, current live control state or full fulfillment completion.

Run `python3 verify.py --source` from this directory to check recorded payload consistency, checksums and matching source bytes. This verifier does not rerun the tests. See the adjacent native queue results for the actual test commands and remaining gates. The original raster files and private workflow candidate remain in protected local storage; generate new labelled dummy rasters for independent reproduction.
