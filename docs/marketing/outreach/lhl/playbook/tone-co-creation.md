# Tone co-creation — 3 personas, 9 drafts

These are exploratory drafts to surface what feels right and what doesn't in Jeff's outreach voice. Once we've reacted to them and extracted patterns, we'll lock the findings into [`voice-guide.md`](../voice-guide.md) and [`anti-patterns.md`](../anti-patterns.md), then update the templates.

Each persona is fictional but realistic. Each draft varies on at least one dimension: opener structure, where the gifted-book ask appears, how directly the differentiation is named, length, tone register.

## Persona 1 — Sarah, parenting Substack writer

- **Channel:** "Slow Mornings" Substack on gentle parenting
- **Subscribers:** ~8K (mix of free + paid)
- **Style:** Long-form essays. Recent post: *"On reading the same book a hundred times."*
- **Audience:** Parents 28–40, mostly women, gift-buying common around birthdays and holidays.
- **Channel for outreach:** Email only (Substack creators don't really respond to social DMs).

**Subject:** Loved your "same book a hundred times" piece — quick collab idea?

```

Either way, would value your read on it. Want me to put one together?

Jeff
Little Hero Labs | littleherolabs.com
```

## How to react to these (for Jeff)

For each draft, in chat:
- **Mark each as one of:** sounds like me / off in some way / doesn't sound like me at all
- **Call out specific phrases that feel wrong** — even one word per draft is useful
- **Note phrases that feel exactly right** — equally useful
- **Comments on length, opener, ask placement, signoff style**

Once we have reactions across all 9, I'll:
1. Extract recurring positive patterns → `voice-guide.md`
2. Extract recurring negatives + AI tells you flag → `anti-patterns.md`
3. Update [`templates/dm-instagram.md`](../templates/dm-instagram.md), [`dm-tiktok.md`](../templates/dm-tiktok.md), [`email-standard.md`](../templates/email-standard.md), [`brief.md`](../templates/brief.md) with the refined examples.

After that, Cycle 1's outreach voice is locked.

## Drafts intentionally vary on these dimensions

- **Opener:** specific reference to a recent post / declarative founder intro / question / praise-then-pivot
- **Differentiation framing:** named ("not pre-made like Wonderbly") / shown ("their actual hair, skin, animal") / implied
- **Where the gifted-book ask falls:** paragraph 1 / paragraph 3 / closing
- **Length:** short DM (~80w) / long DM (~140w) / short email (~150w) / standard email (~200w) / founder-letter (~250w+)
- **Story title mention:** named directly ("Finding Our Inner Voice") / not named / implied via "magical-journey story"
- **Sign-off:** "Jeff / Little Hero Labs" / "Jeff" / "Best, Jeff" / first-name only
- **Ask register:** transactional ("simple partnership structure") / no-strings ("no commitment") / collaborative ("would love your read")
- **Wonderbly differentiation:** named explicitly / paraphrased / not invoked
