# Cron logging current-source evidence overlay

This additive overlay preserves the admission-settlement evidence package, its original source snapshot, suite outputs and historical chain. It inherits every source path and adds the actual Amazon cron logging route and new handler regression. Only the current-source binding layer supersedes the old workflow hashes.

`verify.py --source` verifies the complete current source set, its own evidence and the retained parent package's policy/log integrity. `test-verifier.py` exercises current-source corruption and the parent's original evidence/policy rejection cases against disposable copies. No database, business suite, credential, hosted or provider call is performed by these verifiers.

The prior 44 repair groups and 30 isolation groups are retained dated results. This package does not claim they were rerun, authorize installation/execution, renew live acceptance or prove a deployment. Hosted CI separately runs its unchanged business-safety suites. The workflow change adds one offline credential-log regression; it does not change job activation or production behavior beyond that separately reviewed logging redaction.

Run both commands from the repo root:

```
python3 docs/security/lhl-cron-source-evidence-2026-10-23/verify.py --source
python3 docs/security/lhl-cron-source-evidence-2026-10-23/test-verifier.py
```
